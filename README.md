# sqr-workday-bundle

Official Siliqun Rotor Integration Bundle for Workday HCM & Time Off.

## Capabilities
- Worker profile retrieval with automated WID resolution.
- Guaranteed PII redaction (retaining only public directory attributes: worker_id, name, work_email, title, location, status).
- Time off request submission with ISO 8601 date parsing.
- Teach test fixtures.
